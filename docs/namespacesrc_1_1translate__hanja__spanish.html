Detailed Description

Translates the meanings of the hanja characters from English to Spanish and fills hanja_characters.spanishDefinition.

Uses Google Translate through deep-translator (already in requirements.txt), one request per meaning, one after the other (like process_hanja_data did for French). Translations are saved in data/hanja_spanish_cache.json as they arrive, so the script can be stopped and started again without losing work.

Run from the repository root: python -m src.translate_hanja_spanish
