Detailed Description

Adds Spanish to the existing database without rebuilding it.

  • korean_words: adds spanishLemma and spanishDefinition, filled from the Spanish equivalents (스페인어) of the krdict JSON export.
  • hanja_characters: adds spanishDefinition, left empty until a source is found; the site shows the English meaning while it is empty.

Run from the repository root: python -m src.add_spanish
